# System files shipped by every OTA release (tools/release.sh).
#
#   <repo path>   <absolute destination on the car>   <mode>
#
# Only paths the agent's allowlist accepts (agent/src/manifest.rs,
# system_path_allowed): /usr/local/sbin/rascar-*, /etc/systemd/system/rascar-*
# units and drop-ins, /etc/udev/rules.d/*rascar*.rules, /etc/modules-load.d/rascar*.
# The boot guard (rascar-ota-boot + its unit) is never shipped: it is what
# rolls a bad release back.
#
# A file listed here REPLACES the board's copy at the next boot (the previous
# copy is backed up in the release and restored on rollback). Before the first
# release, diff the board's copies against the repo (docs/ota.md).
# Enabling/disabling units is NOT done by a release.
